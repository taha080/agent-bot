agent-bot

Your own named AI teammates, running locally and free — inspired by the public idea of Grok Bot (a named agent with its own computer that keeps working on multi-step jobs), re-implemented from scratch. No code, design, or assets from any commercial product are used here.

What it does

  • Named bots, each with its own workspace — files, memory, routines.
  • Approvals for sensitive actions — nothing sensitive runs silently.
  • Routines (teach by showing) — save steps, replay them any time.
  • Multi-bot chat — bots hand tasks to each other in one session.
  • Video episode builder — stitch clips from any video model you already use into one episode with narration, burned-in subtitles, chapter overlays, and a "TO BE CONTINUED" end card, in 1920x1080.

Try the bot (live demo, runs in your browser)

This demo mirrors the repo's local-mode bot: try remember launch day is Monday, then recall.

helper> Hi, I'm helper. Try 'remember <fact>', 'recall', or 'files'. You can also attach a file below.

Make a video episode

python -m agent_bot video --script examples/script-day.json \
  --clips-dir ./my-clips --narration ./narration.mp3 --out episode.mp4

Generate clips with your own Grok Bot, Flow, Veo, or another tool you have access to, drop them in --clips-dir, and the builder stitches them with subtitles, chapters, and an end card. Full code and instructions are in the repository.
